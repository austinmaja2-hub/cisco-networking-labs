# Cisco Networking Labs

A collection of hands-on **Cisco Packet Tracer networking labs** developed while studying networking and cybersecurity.

The purpose of this repository is to demonstrate practical knowledge of network design, configuration, troubleshooting, and security.

## Tools

* Cisco Packet Tracer
* Cisco IOS CLI
* IPv4 / IPv6
* Ethernet
* TCP/IP
* VLANs
* Routing & Switching

## Topics Covered

* Network fundamentals
* IP addressing and subnetting
* Switch configuration
* VLANs and trunking
* Inter-VLAN routing
* Static routing
* Dynamic routing
* OSPF
* DHCP
* DNS
* NAT
* Access Control Lists (ACLs)
* Network troubleshooting
* Basic network security

## Cybersecurity Focus

These labs form part of my cybersecurity learning journey, with an emphasis on understanding how networks are designed and configured before progressing into network security and penetration testing.

Understanding networking is essential for areas such as:

* Network reconnaissance
* Traffic analysis
* Network vulnerability assessment
* Firewall and ACL analysis
* Wireless security
* Incident investigation

## Lab Documentation

Each lab contains:

1. Objective
2. Network topology
3. Configuration steps
4. Commands used
5. Testing and verification
6. Troubleshooting
7. Key lessons learned

## Learning Approach

I follow a practical approach:

**Learn → Build → Configure → Test → Troubleshoot → Document**

This repository will be continuously updated as I progress from beginner to advanced networking concepts.
